GET STARTED / 01—03

三步，完成规则导入

规则链接是给 Surge 订阅的，不需要把整份规则文件粘贴到浏览器里阅读。

STEP 01 — 选择

找到你需要的服务

在下方按分类筛选，例如 Netflix、Telegram、Apple 或国内媒体。

STEP 02 — 复制

复制该规则的订阅链接

点击规则卡片上的「复制链接」，链接指向仓库中的原始规则文件。

STEP 03 — 添加

在 Surge 新增规则集

打开 Surge → 首页 → 代理规则 → 新增 → 增加新规则集，粘贴链接并保存启用。

RULE CATALOG / HERMIT BRANCH

找到你要的规则

卡片会标出建议策略。复制链接后，在 Surge 中按你的配置选择对应策略。

ⓘ使用提示　Proxy 表示建议匹配代理策略，DIRECT 表示建议直连。实际策略取决于你的 Surge 配置与节点名称。部分模块或功能可能需要额外配置 MITM。
